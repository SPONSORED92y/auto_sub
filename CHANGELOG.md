# Changelog

## 0.1.0 — 2026-10-18

- Local Windows audio-to-SRT using faster-whisper, with CPU and optional NVIDIA GPU support.
- Traditional Chinese and original English transcription, up to five minutes per audio file.
- Cursor-based split, directional merge, sentence deletion and undo.
- Audio playback highlighting, click-to-seek and optional table following.
- Editable timestamps and conservative automatic split-time recovery.
- Human-readable recognition preferences with hover help, plus output punctuation modes.
- Editable JSON project export and UTF-8 SRT.
- Source distribution, CPU/GPU installation scripts and Windows installation guide.

This release is a source package. A standalone Windows executable and fresh-machine GPU installation validation are not included.
