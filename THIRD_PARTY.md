Dependencies are installed separately; model weights are downloaded on demand.

| --- | --- |

| faster-whisper | MIT — https://github.com/SYSTRAN/faster-whisper |
| CTranslate2 | MIT — https://github.com/OpenNMT/CTranslate2 |
| Streamlit | Apache-2.0 — https://github.com/streamlit/streamlit |
| opencc-python-reimplemented | Apache-2.0 — https://github.com/yichen0831/opencc-python |
| PyAV / FFmpeg | See installed distribution and linked FFmpeg build licenses — https://github.com/PyAV-Org/PyAV |

NVIDIA driver, CUDA and cuDNN have their own licenses and are not included in this source repository. This list is not a complete binary-distribution notice. Before distributing a Windows installer, collect notices and license texts for all transitive dependencies and the exact FFmpeg build.
